# Craps

A casino craps table for Minecraft servers, played in a chest menu with your server's Vault economy.

This repository holds release notes and the latest version number for the plugin's update checker.
The plugin itself is available on BuiltByBit.

- **Latest version:** see [version.txt](version.txt)
- **What's changed:** see [CHANGELOG.md](CHANGELOG.md)

## Requirements

- Spigot or Paper, Minecraft 1.17 to 26.x
- [Vault](https://github.com/MilkBowl/Vault) and an economy plugin (e.g. EssentialsX)

Craps is intended for in-game currency only. It must not be used for gambling with real money.
